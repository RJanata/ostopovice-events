Přístup

Ukládání potřebuje GitHub token s právem zápisu do repozitáře . Vytvoříte ho na GitHubu: Settings → Developer settings → Fine-grained tokens → Generate new token, Repository access: jen tento repozitář, Permissions: Contents a Actions – obojí Read and write (Actions je potřeba jen pro tlačítko „Znovu načíst kalendáře“). Token se uloží jen v tomto prohlížeči.

Aktualizace

Kalendáře se načítají automaticky 3× denně. Když potřebujete změnu ze zdrojů hned (třeba nově přidanou akci v Google kalendáři), spusťte načtení ručně – trvá zhruba 1–2 minuty.
